FAQ

Corporate event management, answered.

Do you handle events with 1,000+ attendees?

Yes — several recent builds, including foundation-day ceremonies, were staged for audiences in the thousands.

Can you manage stage build and AV as one production?

Yes — sound, lighting, LED and the physical build are run as one unit under a single project manager.

How far ahead should we book?

As early as possible once dates are fixed — the earlier we lock venue and crew slots, the more scope we can cover.
